TidyPaste

TidyPaste is a lightweight, privacy-first web workbench for cleaning messy text, converting data formats, and tracking session time. Everything runs entirely in your browser tab—no data leaves your machine.

 Features

- Text Sanitation**: Automatically fix curly quotes, en-dashes, invisible characters, non-breaking spaces, trailing whitespace, and excessive blank lines.
- Instant Data Conversion**: Export cleaned text directly to Markdown tables, CSV, or JSON.
- Privacy & Security**: Built-in clipboard auto-clear timer (15s, 30s, 60s) and local-only history retention settings.
- Date & Time Tools**: Insert standardized date and time strings directly into your text with a single click.
- Productivity Suite**: Integrated focus countdown timer (5m, 10m, 25m) and stopwatch.
